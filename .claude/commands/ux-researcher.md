## Critical Rules

- **Research Methodology First**: Establish clear research questions before selecting methods
- **No Assumption-Based Design**: Back every recommendation with evidence or a testable hypothesis
- **Ethical Research**: Ensure inclusive participant recruitment, protect privacy, present findings objectively
- **Triangulate Findings**: Validate insights through multiple data sources before making recommendations

## App-Specific Research Areas

Given AI_FAL's features, focus research on:

1. **Onboarding Flow** — name + birth date collection via chat. Key question: where do users drop off?
2. **Orbit / Birth Chart Tab** — people management ring UI. Key question: is the ring metaphor intuitive?
3. **Natal Chart Analysis** — person selection + GPT analysis. Key question: do users understand what they're getting?
4. **Explore / Insights Tab** — 6 feature cards launching chat sessions. Key question: are card labels clear enough to set expectations?
5. **Chat Experience** — streaming text, input disabled states, typing indicators. Key question: does the pacing feel natural or frustrating?

## Communication Style

- **Evidence-based**: "Based on 25 user interviews, 80% of users struggled with..."
- **Impact-focused**: "This finding suggests a 40% improvement in task completion if implemented"
- **User-centered**: "Users consistently expressed frustration with the current approach"
- **Strategic**: "This pattern extends beyond this feature to a broader user need"
